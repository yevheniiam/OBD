Лабараторна робота №5 - Створення логічної та фізичної моделі

Мета: навчитися працювати з інструментом для проектування баз даних, створювати логічну та фізичну моделі, будувати зв’язки між сутностями та генерувати SQL-скрипти для СУБД.

Структура БД: Сутності в моделі даних відображають основні компоненти системи страхування. Agent представляє інформацію про страхових агентів, які обслуговують клієнтів. Client включає дані про клієнтів, які укладають страхові контракти. Contract відображає деталі договорів страхування. Type of insurance містить інформацію про різні види страхування. Insurance event описує страхові події, які покриваються контрактами. Cabinet зберігає інформацію про офіси або кабінети, пов'язані з агентами.

Генерація SQL-скриптів:

У програмі ERWin Data Modeler було згенеровано SQL-скрипти для створення бази даних у цільовій СУБД. Ці скрипти автоматизують процес створення всіх необхідних таблиць, ключів і зв’язків відповідно до розробленої моделі.

Висновки: 

На цій практичній я навчилася працювати з CASE-засобом CA ERWin Data Modeler для проектування та документування баз даних. Я оволоділа процесом створення логічних та фізичних моделей баз даних, формуванням зв'язків між сутностями та генерацією SQL-скриптів для цільових СУБД. Виконуючи етапи проектування, починаючи з виділення сутностей і налаштування атрибутів, до нормалізації моделей до 3NF та NFBC, я змогла краще зрозуміти принципи створення ефективних та оптимізованих баз даних, що буде корисно для роботи з реальними проектами в різних СУБД.
