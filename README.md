Опис програми
Назва програми: SchoolSearch
Призначення:
Програма SchoolSearch дозволяє виконувати пошук даних про студентів за різними критеріями. Програма зчитує інформацію з файлу students.txt, де зберігаються дані про студентів (прізвище, ім’я, клас, номер автобуса та вчитель). Програма працює через командний рядок, надаючи можливість шукати студентів за прізвищем, викладачем, автобусним маршрутом або номером класу.
Функціональність:
Пошук студента за прізвищем: Виводить інформацію про студента, включаючи клас та вчителя.
Пошук автобуса за прізвищем студента: Виводить номер автобуса, яким користується студент.
Пошук студентів за прізвищем вчителя: Виводить список учнів, які вчаться у цього викладача.
Пошук студентів за номером класу: Виводить список учнів певного класу.
Пошук студентів за номером автобуса: Виводить список учнів, які користуються певним автобусом.
Відстеження часу пошуку: Для кожної пошукової операції виводиться час виконання.
Використання:
Скомпілюйте та запустіть програму.
У головному меню виберіть відповідний пункт для пошуку.
Введіть потрібну інформацію (наприклад, прізвище студента чи номер автобуса) та отримаєте результат.
Для завершення роботи програми виберіть пункт "Exit".
Формат файлу students.txt:
Файл містить інформацію про студентів у наступному форматі:
StLastName, StFirstName, Grade, Classroom, Bus, TLastName, TFirstName
Приклад:
DROP, SHERMAN, 0, 104, 51, NIBLER, JERLENE
Цей рядок означає: Sherman Drop їде автобусом №51, є учнем дитячого садка, навчається в класі 104 у викладача Jerlene Nibler.
