Лабараторна робота №6 - Реляційна алгебра

Мета роботи: Набути досвіду створення запитів у реляційній моделі баз даних, ознайомитися з основними операціями реляційної алгебри та навчитися застосовувати їх для оптимізації запитів і роботи з даними.

Структура БД: Сутності в моделі даних відображають основні компоненти системи страхування. Agent представляє інформацію про страхових агентів, які обслуговують клієнтів. Client включає дані про клієнтів, які укладають страхові контракти. Contract відображає деталі договорів страхування. Type of insurance містить інформацію про різні види страхування. Insurance event описує страхові події, які покриваються контрактами. Cabinet зберігає інформацію про офіси або кабінети, пов'язані з агентами.

У межах роботи було проаналізовано дві моделі бази даних:
 • ER-діаграма, яка представляє дані про товари, постачальників, проєкти та взаємозв’язки між ними.
 • Фізична модель, яка деталізує структуру бази даних, включаючи співробітників, їхні посади, виплати та обмеження на надбавки.

ЗАВДАННЯ №1:
1. **Предметна область**: постачання товарів для проектів у містах України.  
2. **Таблиця S (Постачальники)**: унікальний код, прізвище, статус (рейтинг/репутація), місце розташування.  
3. **Таблиця P (Товари)**: опис, колір, вага, місто доступності.  
4. **Таблиця J (Проекти)**: унікальне ім'я, місто реалізації (школи, офіси тощо).  
5. **Таблиця SPJ (Поставки)**: постачальник, товар, проект, кількість (унікальна комбінація S#P#J#).  
6. **Ціль моделі**: аналіз доступності товарів, ефективності постачальників і потреб проектів.

Щоб виконати завдання №2, потрібно детально описати мовою реляційної алгебри один із запитів, який відповідає моєму варіанту і був використаний під час виконання робіт № 3,4,5. Необхідно обрати найбільш значущий запит і побудувати його відповідно до предметної області.

Запит1 : Чи є договори, укладені агентами по тих видах страхування, в яких вони не спеціалізуються.


Запит в реляційний алгебрі має наступний вигляд: 


((Contract WHERE Type_of_insurance NOT IN (Agent_Type_of_insurance WHERE Agent_ID = Contract.Agent_ID)) JOIN Agent [Agent_ID]) PROJECT [Contract.*, Agent.First_name, Agent.Last_name, Agent.Address]

Висновки: Під час виконання роботи була досягнута основна мета — набуття практичних навичок у створенні запитів для реляційних баз даних. За допомогою реляційної алгебри було реалізовано запити для обчислення загальної суми виплат співробітнику за визначений період та деталізації цих виплат по місяцях. Це дозволило ознайомитись з основними операціями реляційної алгебри, такими як селекція, агрегація та групування, а також навчитись ефективно застосовувати їх для роботи з даними.
